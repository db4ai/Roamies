What this adds
  • One provider entry, local, listed as “Local · Light LLM” — kept out of the cloud sign-in verbs.
  • Connect to your OpenAI-compatible gateway with a base URL and an optional API key (empty = keyless; no header sent).

  • Key stored in the macOS Keychain like the Fish key; no key is typed into logs or config.

The payoff
  • Spoken replies come from your TTS service, not Fish Audio — no signup, no API key, no per-token bill.
  • Everything after the panel stays identical: the reply streams, gets split into sentences, and is played through the existing audio path. Local vs Fish is a swappable transport, same emit({ kind:'speech', pcm }).
  • If the TTS server is unreachable, spoken replies safely fall back to text — never an error, never a crash.
  • Listening never changes — it already runs on-device. No new microphone permissions.
